## 📖 Présentation  

**GuestSecretCode** est un jeu de console en **Java** où le joueur doit deviner une combinaison secrète générée aléatoirement.  
L’objectif est de proposer des combinaisons et d’analyser les indices fournis sur le nombre de chiffres correctement placés.  
Le défi ? Trouver la bonne combinaison en un **minimum de tentatives** !  

## 🎲 Comment jouer ?  

1. **Lancement du jeu** : Après l’exécution du programme, choisissez la longueur de la combinaison à deviner.  
2. **Proposition** : Saisissez une combinaison de chiffres.  
3. **Indices** : Le jeu vous indique combien de chiffres sont bien placés.  
4. **Victoire** : Continuez jusqu'à trouver la combinaison secrète !  

## 🚀 Installation  

### Prérequis  
- **Java JDK 8+** : Assurez-vous d'avoir Java installé sur votre machine.  
- **IDE ou Terminal** : Vous pouvez exécuter le jeu dans un IDE (NetBeans, IntelliJ, Eclipse) ou directement via un terminal.  

### Étapes d’installation  

1. **Cloner le dépôt**  
   ```sh
   git clone https://github.com/TolMen/GuestSecretCode.git
   ```  
   OU  
   ```sh
   git clone git@github.com:TolMen/GuestSecretCode.git
   ```  

2. **Compiler le projet**  
   Dans un terminal, accédez au dossier du projet et compilez le code :  
   ```sh
   javac GuestSecretCode/GuestSecretCode.java
   ```  

3. **Exécuter le jeu**  
   Une fois la compilation terminée, lancez le jeu avec :  
   ```sh
   java GuestSecretCode.GuestSecretCode
   ```
